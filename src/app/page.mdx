<Tabs items={["Homebrew", "Install script"]}>
<Tab>

```bash
brew install keploy/tap/keploy
```

</Tab>
<Tab>

```bash
curl --silent -O -L https://keploy.io/install.sh && source install.sh
```

</Tab>

## Steps

<Steps>

### Start Mongo

```bash
docker compose up -d mongo
```

### Record

Run `keploy record`.

</Steps>

## Troubleshooting

<Troubleshoot title="network keploy-network declared as external, but could not be found">

Create it once:

```bash
docker network create keploy-network
```

</Troubleshoot>
